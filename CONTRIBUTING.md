# Contributing

Describe the problem, expected behavior, PowerShell version and affected object type. Use sanitized or synthetic evidence. Never attach a real application XML or report containing internal information without reviewing and removing sensitive data.

Keep Windows PowerShell 5.1 compatibility and read-only provider behavior. Do not execute discovered scripts. Preserve raw evidence exports and HTML encoding. Update the changelog and documentation when report schemas or scope change.

For changes to provider scanning, validate with known references in a permitted test environment and report coverage. For UI changes, test search, type filtering, both grouping modes, empty results and the default collapsed diagnostics. Clearly state checks that could not run.
