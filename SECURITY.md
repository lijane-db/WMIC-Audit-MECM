# Security

The tool reads provider definitions and explicit source files, and writes local reports. Reports can expose command-line credentials, internal paths and object names. Treat them as internal audit data.

Do not include sensitive evidence in a public GitHub issue. Before publishing the repository, configure GitHub private vulnerability reporting or provide a private contact channel, then document that channel here.

Reports use no external dependencies. Matched content is HTML-encoded and UI labels are inserted as text. Do not modify the report to execute matched commands or inject raw evidence into HTML.
